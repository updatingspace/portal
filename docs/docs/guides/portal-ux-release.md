## Публикация и откат

Рабочий каталог оператора: `/tmp/portal-ux-release`. Публикация сначала загружает
новые assets, затем `404.html` и `index.html` с `no-cache, no-store`. Старые assets
сохраняются, предыдущие index/404 копируются до переключения. Публичные маршруты,
хеши JS/CSS и отказ без сессии проверяются после переключения.

Для отката frontend используется `rollback_frontend.py`; скрипт сначала сверяет
текущий index с выпускаемой версией. Для отдельного backend:
`python3 /tmp/portal-ux-release/deploy_release.py <service> --rollback`.
Откат проверяет активную ревизию и восстанавливает предыдущий digest с исходной
конфигурацией. Runtime-конфигурации имеют права `0600`, не входят в git и публичный
архив. Перед новым Terraform apply следует согласовать образы с этим manifest
и проверить plan.

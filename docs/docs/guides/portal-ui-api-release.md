## Изменения

- Персонализация проходит через BFF в Access. Отсутствовавший маршрут давал
  `404` для preferences, defaults и dashboard layouts.
- Activity использует совместимость с django-ydb-backend, уже применяемую в
  других сервисах. Сериализация JSON больше не вызывает `json.load(dict)` при
  сохранении подписки; сортировка курсора outbox использует столбец вместо
  `ORDER BY 1`, который YDB отклонял при открытии live-ленты.
- В serverless окружении BFF возвращает событие перехода на опрос ленты каждые
  15 секунд. `BFF_FEED_STREAMING_ENABLED=false` сохранён и в Terraform.
  При ошибке EventSource закрывается, исключая параллельные переподключения.
- Светлая, тёмная и автоматическая темы согласуют фон и текст, в том числе при
  недоступной персонализации и высоком контрасте. Шрифт использует системный стек
  без загрузки Google Fonts.
- Страницы управления сообществом показывают имена людей, названия ролей,
  описания прав и событий. UUID, коды и JSON доступны по раскрытию технических
  данных. Просмотр роли отделён от редактирования; обзор считает роли сообщества
  отдельно от системных шаблонов.

## Проверки

- BFF: 127 тестов и 19 subtests, включая маршрутизацию персонализации, отказ без
  сессии и при несовпадении tenant, конечный SSE-ответ для serverless.
- Activity: 56 тестов, включая API подписок, JSON/UUID в YDB compiler и сортировку
  курсора live. Чтение настоящего outbox в release-образе с production YDB выдаёт
  начальное событие `ready`.
- Frontend: lint (0 ошибок, 5 существующих предупреждений), TypeScript/build,
  16 Vitest тестов и 9 Chromium сценариев: контраст светлой/тёмной темы,
  автоматическое переключение, недоступность настроек, роли и аудит.
- Production: чтение Activity subscriptions, Access defaults и dashboard layouts —
  `200`. Все четыре публичных маршрута без сессии возвращают `401`. Публичный HTML
  ссылается на новую сборку; хеши JS/CSS совпадают. Index и 404 после загрузки
  проверены чтением из Object Storage.
- Проверка записей в production и использование cookie действующей пользовательской
  сессии не выполнялись: автоматическая проверка разрешений отклонила эти способы
  диагностики. Запись проверена локальными API-тестами и тестами YDB compiler;
  полный пользовательский сценарий в production не подтверждён браузерной сессией.

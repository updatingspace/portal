title: Portal — исправления событий и управления, октябрь 2026
---

Этот выпуск исправляет загрузку событий на главной и в календаре, использует
часовой пояс клиента, упрощает фильтры и оставляет заголовок/геометрию списка
при первоначальной загрузке. Голосования, редактор достижений и изменённые
интерфейсы управления используют выбранный русский или английский язык.

Модерация и история привязаны к публикации. Управление участниками и заявки
собраны в управлении сообществом; системные заявки по-прежнему доступны только
системному администратору. Роли назначаются после подтверждения, группы и команды
выбираются по названию из текущего tenant. Старый `/admin` перенаправляет в этот
раздел, а разрешения системных действий не расширяются.

Создание feature flag возвращает `409`, если ключ уже существует, и не перезаписывает
его. Сервис подключает общий адаптер JSON/UUID для YDB: ошибка сериализации при
записи аудита/outbox больше не приводит к `500` после создания флага. Новый
`check_ydb_feature_flags.py` проверяет настоящий HTTP-контракт, аудит и outbox
в локальной YDB; включён в CI.

Порядок выпуска: Access (каталог прав), Activity (аудит), Gamification
(изображения и категории), Feature Flags (YDB), затем frontend. Для Access
выполняется `seed_access_defaults`; в SQL также применяются миграции значений
часового пояса. Новых столбцов YDB нет. Gamification получает Pillow и доступ
к существующему media bucket; значения секретов не меняются.

Публичный UI не создаёт фичу продукта самим заведением флага: ключ должен
поддерживаться кодом приложения. Пустой список, ошибка чтения и отсутствие
совпадений поиска представлены отдельно.

## Проверки перед выпуском

- Node 22.12.0, pnpm 10.28.2: lint без ошибок (одно существующее предупреждение
  эффекта dashboard), TypeScript, production build.
- Vitest: 559 passed, 1 skipped; после последних изменений дополнительно
  23 проверки карточки события, ленты и административных подписей.
- Playwright: 72 сценария проверены; полный прогон дал 70 passed и две ошибки
  пробела в подписи аудита. После исправления повторены оба сценария и семь новых
  сценариев выпуска — 9 passed. Темы, ширины 360–1280, английский интерфейс,
  локальное время, восстановление форм после отказа и работа диалогов.
- Access: 164 tests и 3 subtests; Activity: 24; Gamification: 17;
  Feature Flags: 10. Ruff проходит во всех четырёх сервисах.
- Подписанный multipart проверяется до разбора файла; тест включает файл на
  границе 2 MiB и отказ по неверной подписи без обращения в storage.
- Локальная YDB: HTTP-создание флага, дубликат 409, аудит/outbox, фильтры событий
  и личные достижения. Access `makemigrations --check --dry-run`: без изменений.

Замоканные браузерные ответы не подтверждают реальный вход через UpdSpaceID
или доставку писем. Внешние экраны ID этим выпуском не меняются.
